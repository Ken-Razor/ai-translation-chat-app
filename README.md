ViveTalk is a modern, high-performance cross-platform mobile chat application featuring **100% Live Neural AI Translation**, **Phrase-Aware Tone Pinyin**, and **Low-Latency Voice & Video Calling**.

---

## ✨ Features

- 🌐 **100% Live Neural AI Translation**: Zero-dictionary live auto-detection and translation across English, Indonesian, Chinese (Mandarin), Spanish, French, German, and Japanese.
- 🗣️ **Phrase-Aware Chinese Pinyin Engine**: Multi-syllables phrase matching with accurate 4-tone diacritics (`ā`, `á`, `ǎ`, `à`).
- 📞 **Voice & Video Calling**: Real-time dual-way audio streaming and video call modal interfaces.
- 🎨 **Modern Dark Mode Aesthetic**: Curated HSL color palette, smooth micro-animations, glassmorphism elements, and modern typography.
- ⚡ **Instant Signal Synchronization**: Direct polling integration with high-concurrency Golang backend.

---

## 🛠️ Technology Stack

- **Framework**: React Native with Expo (SDK 54)
- **Audio & Video**: `expo-av`, `expo-camera`, `react-native-webrtc`
- **Translation Engine**: Free Google Neural AI Live Translation Integration
- **Storage**: `@react-native-async-storage/async-storage`
- **Icons**: `@expo/vector-icons`

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Expo Go App on iOS/Android (or Web Browser)

### Installation

```bash
# Clone repository
git clone https://github.com/ken-razor/ai-translation-chat-app.git
cd ai-translation-chat-app

# Install dependencies
npm install

# Start Expo development server
npx expo start
```
